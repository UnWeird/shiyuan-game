# 十元桌游 - 数字版

一个基于六边形网格的回合制战略游戏，灵感来源于十元桌游。

## 游戏规则

### 基础设定
- **地图**: 边长为 5 的六边形网格，分为起始区和交战区
- **单位类型**:
  - 步兵（一角）: 移动1格，近战攻击
  - 骑兵（两角）: 移动2格，受伤退化为步兵
  - 弓箭手（五角）: 移动1格，无限射程但需朝向
  - 将军（一元）: 特殊技能单位
- **预算**: 每个玩家 4 元预算配置部队 + 1 元将军
- **生命值**: 每个单位有 2 点生命值（正反两面）

### 将领
1. **无双**: 扇形群体攻击，掷骰子决定攻击数
2. **神机**: 可组装机关单位（弩车、战车）
3. **仁德**: 可转化敌方/中立单位

### 行动系统
- 行动点由骰子决定（每部署 1 元 = 1 颗骰子）
- 每回合首次击杀额外获得 1 颗骰子
- 每个单位每回合最多 2 个行动，每种行动最多 1 次
- 行动类型: 部署、移动、攻击、转向（各消耗 1 点）

### 胜利条件
己方单位触碰到敌方大本营

## 技术栈

- **前端**: React + TypeScript
- **状态管理**: Zustand
- **样式**: TailwindCSS

## 游戏流程

1. **选择将领**: 玩家1和玩家2分别选择自己的将领
2. **配置部队**: 使用 4 元预算配置步兵、骑兵、弓箭手的组合
3. **设置大本营**: 在己方起始区设置大本营位置
4. **部署阶段**: 掷骰子，使用行动点部署单位
5. **行动阶段**: 移动、攻击，执行策略
6. **胜利判定**: 先触碰到敌方大本营者获胜

## 开发笔记

### 六边形坐标系统
使用 Cube Coordinates（立方坐标系），满足 `q + r + s = 0`
- 便于计算距离: `distance = (|q1-q2| + |r1-r2| + |s1-s2|) / 2`
- 便于获取邻居和范围

### 架构设计
- 状态管理使用 Zustand，简单高效
- 组件化设计，易于扩展
- 六边形工具函数独立封装
- 游戏逻辑通过 Hooks 复用
